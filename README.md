## About This Space

[nirmalkharal.dev](https://www.nirmalkharal.dev) is my personal corner of the internet. It is part introduction, part playground, and always evolving.

- Motion-led storytelling with GSAP and Motion
- Responsive layouts for screens large and small
- Light and dark themes based on system preferences
- Reduced-motion support for accessible browsing
- Custom typography, sound details, and an animated preloader
- A component-based foundation built with Next.js and React

## Run It Locally

```bash
git clone https://github.com/kharalnirmal/nirmalkharal.git
cd nirmalkharal
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000) to see it in motion.

| Command | Purpose |
| :-- | :-- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Check the code with ESLint |
